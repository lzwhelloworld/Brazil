## 功能亮点

### 1. 安全评级体系（巴西专属）
每个区域都有独立安全评分：
- 白天/晚上分别评估
- 步行安全边界明确
- 哪些区域一票否决
- 外派社区实测验证

### 2. 真实租金参考
基于 QuintoAndar 平台 2025-2026 实际挂牌数据统计，每个区域给出：
- 纯租金区间
- 含物业+IPTU+保险的总支出区间
- 为什么"标价≠实际支出"（巴西租房隐藏费用占30-50%）

### 3. 30+项看房清单
涵盖：
- 🔒 安保检查（门禁、周边安全路线）
- 💰 费用明细（租金、物业、IPTU、保险、水电网）
- 🏠 房屋状况（噪音、朝向、漏水、家电）
- 📋 合同条款（租期、退租、涨租、验房）

### 4. 巴西租房避坑指南
- 假中介诈骗识别（OLX/FB Marketplace 别碰）
- "提灯定损"退租纠纷防护
- 担保保险 vs 押金 vs 担保人，三选一怎么选
- 看房安全守则
